React Bits source was obtained from its official repository because the referenced conversation snippets were not attached to this session. Changes: React JSX imports for the existing compiler, removal of Next-specific directives, WebGL capability checks, lower DPR, visibility pausing, explicit cleanup, bounded mounting and palette/interaction configuration. PixelSwap receives only two static color/brand surfaces; no live workbench, charts or WebGL scenes are cloned.

New separately installed packages: `three@0.186.1` (MIT), `ogl@1.0.11` (MIT), development types `@types/three@0.186.0` (MIT). Exact package closure/integrities are generated by npm in `web/package-lock.json`. No external font package, CDN script, animation framework or stock image is used. Existing React/Vite/TypeScript versions are unchanged. Dependency notices remain in packages and production license comments; effect-source terms are additionally retained in this repository.

The mark and favicon are original line geometry. The hero is real procedural WebGL, with an explicitly identified static SVG fallback when WebGL is unavailable; the fallback is not represented as a 3D renderer.
